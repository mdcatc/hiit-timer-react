# Hiit Timer


## Usage
This is a simple Hiit Timer that allows you to create and run workouts using markdown syntax.


## Markdown Syntax

- `##` is used to define a section (e.g. Warm-Up, Main Set, Cool Down)
- Putting `(Repeat X)` after a section name is used to define a sub-section (e.g. Repeat 3x)
- `-` is used to define an exercise (e.g. Push-Ups: 10s)


## Example

```markdown
## Warm-Up
- Jumping Jacks: 15s
- High Knees: 15s
- Rest: 15s

## Main Set (Repeat 3x)
- Push-Ups: 10s
- Squats: 10s
- Lunges: 10s
- Rest: 15s

## Cool Down
- Stretch: 15s
```
